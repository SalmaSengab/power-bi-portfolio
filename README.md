# Power BI Portfolio

A collection of Power BI dashboards built to practice and showcase data modeling, DAX, and interactive report design across different domains — from HR/recruiting analytics to sales performance.

Each project lives in its own folder with the `.pbix` report, the source data, and its own detailed README.

---

## Projects

| Project | Description | Data | Report Pages |
|---|---|---|---|
| [`job-postings/`](./Job-Postings-Dashboard) | Analysis of ~17,500 tech/analytics job postings (2017–2021) — job titles, in-demand skills, salaries, and company profiles | `job_postings.csv` | 9 pages: Company, Jobs, Skills, Job Level Analysis, Job Titles, Salary Analysis, Skill Analysis, Skill Likelihood, Experience Analysis |
| [`sales/`](./Sales-Dashboard) | Sales performance analysis on an AdventureWorks-style dataset (~23,600 order lines, 2011–2014) — revenue, territories, products, and order status | `Sales.xlsx` | 5 pages: Overview (x2), Scatter Plot, Orders, Products |

---

## Tools & Skills Demonstrated

- **Power BI Desktop** — end-to-end report building
- **Power Query** — data cleaning, shaping, and transformation
- **DAX** — calculated measures, KPIs, and time intelligence
- **Data modeling** — relationships, hierarchies, and slicers/filters
- **Dashboard design** — KPI cards, scatter/line/bar/area charts, treemaps, pivot tables, and custom tooltips
